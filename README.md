# 校园食堂双端管理系统
毕业设计｜SpringBoot3 + Vue3 + 微信小程序

## 技术栈
后端：SpringBoot3、MyBatis‑Plus、MySQL、Redis
前端：Vue3 + Vite + Element‑Plus、ECharts
移动端：微信原生小程序

## 项目简介
实现PC管理端、商家端、网页用户端、微信小程序；包含登录鉴权、菜品管理、购物车、订单流转、充值退款模块；完成数据库设计、接口开发、性能调优与完整测试用例。

## 模块说明
1. springboot 后端SpringBoot代码
2. vue Vue3前端代码
3. miniprogram 微信小程序代码
4. files 项目文档与静态资源
5. add_new_features.sql 数据库建表脚本
